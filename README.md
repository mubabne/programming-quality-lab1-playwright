# Лаборатори 1 — Playwright

Ч. Мөнхбаяр — B242270045

**Хийсэн ажил**

SauceDemo дээр зөв нэвтрэх, буруу нууц үгээр нэвтрэх, бараа сагсанд нэмэх гэсэн 3 тест бичсэн. Нэвтэрсэн тест бүр гарах үйлдлээр дуусна. Гурван хөтөч дээр нийт 9 тест амжилттай ажилласан.

**Код бичүүлэхэд ажигласан зүйл**

Codegen-ий код ажилласан ч өөрийн бичсэн тестийг уншихад арай амар байсан. Үүссэн код data-test атрибутаар элемент олж, талбарт утга оруулахаас өмнө давхар товшсон. Харин үндсэн тест getByRole, getByPlaceholder ашигласан. Үүссэн код үр дүн шалгаагүй тул сагсны тоо, товчны төлөвийг үндсэн тестэд тусад нь шалгасан.

[Бичүүлсэн код](docs/codegen-login.ts)

**XPath яагаад ашиглаагүй вэ?**

Товчийг нэрээр нь, талбарыг тайлбараар нь олоход ойлгомжтой байсан. Хуудасны бүтцийг дагасан урт XPath нь бүтэц өөрчлөгдөхөд эвдэрч болно. Сагсны тоонд богино CSS сонгогч ашигласан.

**Алдаа шалгасан нь**

Барааны гарчгийг зориуд буруу бичиж тестийг унагасан. Алдааны бичлэгт нэвтрэлт амжилттай боловч байхгүй текстийг 5 секунд хүлээсэн нь харагдсан. Зөв текстийг буцааж тавихад бүх тест амжилттай болсон.

[Зөв ажилласан бичлэг](docs/successful-login-trace.zip) · [Алдааны бичлэг](docs/intentional-failure-trace.zip) · [Тайлбар](docs/trace-exercise.md) · [Тестийн тайлан](docs/test-report.html)

**Playwright ба Selenium**

Playwright, Selenium хоёулаа хөтөч дээр үйлдэл автоматжуулдаг. Playwright нь элементийг бэлэн болохыг автоматаар хүлээдэг. Selenium-д хүлээх нөхцөлийг тусад нь тохируулж болдог. Playwright Test-д тест ажиллуулах, үр дүн шалгах, тайлан гаргах хэрэгсэл хамт байдаг. Энэ лабораторид нэг тохиргоогоор гурван хөтөч дээр тест ажиллуулахад амар байсан.

**Хиймэл оюуны тусламж**

Тест болон тайлбарт хиймэл оюуны тусламж авсан. Эхний хувилбарт гарах үйлдэл дутуу байсан. Үүнийг хоёр тестэд нэмсэн. Сагсны шалгалтыг мөн сайжруулсан. Засварын дараа гурван хөтөч дээр шалгасан.

Эх сурвалж: [Элемент сонгох](https://playwright.dev/docs/locators), [Код бичүүлэх](https://playwright.dev/docs/codegen), [Selenium-ийн хүлээлт](https://www.selenium.dev/documentation/webdriver/waits/).
